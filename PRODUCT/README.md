# PRODUCT — файлы Полины (продуктовая часть ВКР «Хвостун»)

Источники теоретического анализа продуктовой части, по блокам рабочей гипотезы. Структура повторяет слой `wiki/` (см. [AGENTS.md](../AGENTS.md)), но живёт отдельно, чтобы не смешивать продуктовый теоранализ с ML-вики.

| Папка | Что внутри | Правило |
|---|---|---|
| `sources/` | Одна страница на источник: библиография, DOI, роль в блоке, что даёт, статус проверки, куда идёт в ВКР | Создаёт и обновляет агент; статус проверки обязателен |
| `статьи/` | PDF статей под открытыми лицензиями (CC BY и аналогичные); платные тексты не кладём | Только чтение |

Навигация — [index.md](index.md). Журнал — [log.md](log.md). Блоки добавляются по мере разбора: эффективность → качество → удовлетворённость → коммерция → слайд проблемы.

## Как добавлять источник

1. Проверить по первоисточнику (DOI, Crossref, сайт журнала): авторы, год, журнал, выборка, цифры.
2. Создать `sources/<фамилия>-<год>-<2-3 слова>.md` с frontmatter `type: source`, `tags`, `block`, `status`, `doi`, при наличии `raw_path` и `license`.
3. Если статья под открытой лицензией — положить PDF в `статьи/`.
4. Добавить строку в `index.md` и запись в `log.md` (`## [YYYY-MM-DD] ingest | Название`).
