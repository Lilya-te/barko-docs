# Statistical Power Analysis for the Behavioral Sciences

**Библиография:** Cohen J. (1988). Statistical Power Analysis for the Behavioral Sciences. 2nd ed. Lawrence Erlbaum.  

## Роль в блоке «Эффективность»

Размеры эффекта: +1 балл ≈ 0,7 SD — средний эффект

## Что даёт

Условные ориентиры размера эффекта d: 0,2 — малый, 0,5 — средний, 0,8 — большой. Основа расчётов мощности.

## Статус проверки

Классика, книга; общеизвестно.

## Куда идёт в ВКР

Порог «+1 балл» самоэффективности ≈ 0,7 SD (SD 1,46 по вопросу об уверенности в опросе) — чуть выше среднего эффекта; расчёт мощности парного сравнения при 30 парах ≈ 0,95.
