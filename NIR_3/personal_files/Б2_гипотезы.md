# Личные исследовательские гипотезы

Пайплайн проверки: `Б3_Разработать пошаговую методику проверки гипотезы и (для ML) пайплайн оценки.md`.  
**Правило:** при изменении H₁ / H₀ / порогов / метрик обновлять **оба** файла (этот и Б3) и wiki; см. `.cursor/rules/nir3-hypotheses-pipeline-sync.mdc`.

# 1. **H₁-baseline (rule-based).** 
Если по доменным скорам C-BARQ(Mini) анкет владельцев на 7–14 день применять заранее зафиксированный rule-based mapping «домен + порог T → пункт(ы) каталога», то на val macro-F1 будет не ниже 0.6 (верно не менее 3 из 5) и выше случайного выбора 5 рекомендаций из каталога.

$$
N = 40,\quad \lvert G\rvert = \lvert P\rvert = 5 \implies \mathbb{E}[F1_{\mathrm{random}}] = \frac{5}{40} = 0.125
$$

   - **H₀:** `macro-F1 < 0.6`
   - **Метрика** на анкету i:

$$
TP_i = \lvert P_i \cap G_i \rvert,\quad \mathrm{F1}_i = \frac{TP_i}{5},\quad \text{macro-F1} = \mathrm{mean}_i(\mathrm{F1}_i)
$$

# 2. **H₁-plan**
## 2.1. **H₁-plan-DT (rule-based vs DecisionTree).** 
Если по признакам анкеты C-BARQ(Mini) и профиля собаки (порода / возраст / история приюта и т.п.) на волне 7–14 дней обучить дерево решений (DecisionTree), предсказывающее набор рекомендаций из каталога (N = 40), то на том же val, что у rule-based,

$$
\Delta_{\mathrm{DT}} = \text{macro-F1}_{DT} - \text{macro-F1}_{baseline} \ge \delta,\quad \delta = 0.10
$$

   (rule-based mapping «домен + порог T»).  
   - **H₀:** `Δ_DT < 0.10`
   - **Метрика:** та же example-F1, что в H₁-baseline (см. формулы выше); сравнение на одном и том же val; top-5 по скорам/голосам листьев.
   - **Интерпретация δ:** +0.10 macro-F1 ≈ **+0,5 верной рекомендации из 5** на анкету; порог практической значимости, при котором DT считается оправданнее алгоритма (недостаточно строгого «больше»).

## 2.2. **H₁-plan-LR (rule-based vs LogisticRegression OvR).** 
Если по тем же признакам на волне 7–14 дней обучить LogisticRegression в схеме **one-vs-rest** (отдельный бинарный классификатор на каждый из N = 40 пунктов каталога), то на том же val, что у rule-based,

$$
\Delta_{\mathrm{LR}} = \text{macro-F1}_{LR} - \text{macro-F1}_{baseline} \ge \delta,\quad \delta = 0.10
$$

   - **H₀:** `Δ_LR < 0.10`
   - **Метрика:** та же example-F1; top-5 по вероятностям OvR (без переобучения порогов на val).

**Сравнение моделей:** обе оцениваются на одном val; в H₁-quality идёт кандидат с большим Δ (при обоих `Δ ≥ 0.10` — лучший; если оба `< 0.10` — rule-based).

# 3. **H₁-quality (ML → эксперт).** 
Если рекомендации плана адаптации строит выбранная ML-модель (DT или LR OvR) по признакам анкеты C-BARQ(S) и профиля собаки (порода/возраст/история приюта и т.п.) и кинолог валидирует их по схеме «принять / править / отклонить», то на val из N анкет доля «принять» ≥ ~60–70%, «безопасна» ≥ ~97–98%.  
   - **H₀:** доля «принять» < 60% или доля «безопасна» < 97%
   - **Метрика:**

$$
P_{\mathrm{accept}} = \frac{N_{\mathrm{принять}}}{N_{\mathrm{всего\ рекомендаций}}}
$$

править / отклонить не считаются «принять».

# 4. **H₁-transfer (РФ vs референс).** 
Если сравнивать доменные скоры C-BARQ(S) российского пилота с выбранным референсом (например short C-BARQ / Bohland post-adoption) по ключевым доменам, то различия лежат внутри заранее заданного δ (тест эквивалентности / TOST), α = 0.05.  
   - **H₀:** хотя бы по одному ключевому домену |Δ| ≥ δ (неэквивалентность)
   - **Примечание:** p > 0.05 в тесте на *различие* само по себе гипотезу не подтверждает.

# 5. **H₁-channel (NLP-заполнение vs self-report).** 
Если по тексту чата с владельцем (письменный Q&A или транскрипт голоса) заполнять пункты C-BARQ(Mini) через NLP (эмбеддинги + косинусное сходство с формулировками ответов/шкалы), то доменные скоры NLP-заполнения эквивалентны скорам ручного self-report того же владельца: по каждому ключевому домену различия лежат внутри заранее заданного δ (TOST), α = 0.05.  
   - **H₀:** хотя бы по одному ключевому домену |Δ| ≥ δ (неэквивалентность)
   - **Метрика:**

$$
\Delta_d = \bar{s}_{d,\mathrm{NLP}} - \bar{s}_{d,\mathrm{self}}
$$

подтверждение — оба односторонних теста TOST значимы при α = 0.05.  
   - **Примечание:** p > 0.05 в тесте на *различие* само по себе гипотезу не подтверждает.

# 6. **H₁-human-eval.** 
Если в слепом pairwise A/B эксперты сравнивают ответ K5-RAG с baseline (без RAG / без wiki-контекста) на одном и том же наборе запросов, то доля предпочтений в пользу K5-RAG ≥ 70% и значимо выше 50% (случайный выбор) при α = 0.05; при ничьей засчитывается «нет предпочтения».  
   - **H₀:** доля предпочтений K5-RAG ≤ 50% **или** < 70%
