# Персональные данные и 152-ФЗ в Hvostun

Практический чеклист для частей проекта, где есть ПДн владельцев/волонтёров. Источник норм: [fz-152-personal-data](../sources/fz-152-personal-data.md) (`152 ФЗ.md`).

## Где в Hvostun есть ПДн

| Место | Примеры ПДн |
|-------|-------------|
| Сбор анкет (Яндекс Форма, позже бот/приложение) | email, телефон, согласие, метаданные ответа |
| Research-ops Postgres | `users`, `consents`, связка владелец↔собака |
| K5 / чат (позже) | сообщения пользователя, контакты |
| Извлечение ответов анкеты из чата / Амелько (roadmap) | реплики, подтверждённые ответы, связка с собакой — см. [k5-k3-answer-bridge](k5-k3-answer-bridge.md) |
| Экспорт для ML | не должен содержать прямые идентификаторы |

Данные о собаке без привязки к человеку — не ПДн; с контактом владельца — обработка ПДн.

## Чеклист перед сбором / фичей с ПДн

1. **Цель** обработки сформулирована и совпадает с тем, что сказано субъекту.
2. **Минимизация** полей: только нужное для цели (не копировать лишнее из полной C-BARQ-демографии).
3. **Согласие** отдельным шагом, версия текста (`consent_v1`…), фиксация факта и времени; есть способ отзыва — шаблон: [consent-v1-pilot-form](consent-v1-pilot-form.md).
4. **Политика** обработки ПДн доступна со страницы/формы сбора.
5. **Хранение в РФ** при сборе ПДн граждан РФ (ст. 18 ч. 5) — Яндекс Формы / РФ-хостинг, не Google Forms как основное хранилище.
6. **Поручение** обработке (Яндекс и др.) осознано: оператор отвечает перед субъектом.
7. **Срок хранения** и процедура уничтожения/обезличивания после цели.
8. **Разделение** ops (с ПДн) и training (обезличенный export) — см. [research-data-app](research-data-app.md), [data-harmonization](data-harmonization.md).
9. **Уведомление** уполномоченного органа (ст. 22) — ops-задача до/при старте обработки.
10. **Инциденты**: готовность уведомить в 24ч / 72ч (ст. 21 ч. 3.1).
11. **K3/авторешения**: скоры и рекомендации не оформлять как юридически значимое авторешение о человеке без правовой рамки (ст. 16).
