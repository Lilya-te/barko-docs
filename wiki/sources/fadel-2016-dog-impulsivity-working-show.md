# Source: Импульсивность — рабочие vs выставочные линии (Fadel et al. 2016)

**Оригинал:** [`статьи/foreign/uk/Fadel_2016_DIAS_dog_impulsivity_working_show_lines.pdf`](../../статьи/foreign/uk/Fadel_2016_DIAS_dog_impulsivity_working_show_lines.pdf)

Fadel, F. R., Driscoll, P., Pilot, M., Wright, H., Zulch, H., & Mills, D. S. (2016). Differences in Trait Impulsivity Indicate Diversification of Dog Breeds into Working and Show Lines. *Scientific Reports, 6*, 22162. https://doi.org/10.1038/srep22162. CC BY 4.0.

## Саммари

### Суть

Сравнение **trait impulsivity** (DIAS) между и внутри двух пород с выраженным делением на **рабочие и выставочные линии**: Border Collie (herding) и Labrador Retriever (gun work). Гипотеза: рабочие collies импульсивнее рабочих labrador; **show lines** двух пород сходнее между собой, чем working lines внутри породы.

### Данные

| Параметр | Значение |
|----------|----------|
| DIAS + демография | онлайн, 2 недели рекрутинга |
| После QC | 1495 анкет; **1161 purebred** для сравнения пород |
| Border Collie | n = **716** |
| Labrador Retriever | n = **445** |
| Линии | work 56.5%, show 16.6%, mixed 19.6%, other 7.2% |
| Возраст | 1–20 лет |

### DIAS — структура (репликация)

- 18 items → 3 фактора (как Wright et al. 2011): **behavioural regulation**, **aggression threshold & response to novelty**, **responsiveness**.
- Рекомендация авторов: **удалить** item «My dog appears to be 'sorry' after it has done something wrong» (не грузится на факторы; интерпретация «вины» у собак спорна).
- OQS α ≈ 0.73–0.74; фактор 3 responsiveness α низкий (~0.45) — ограничение инструмента.

### Ключевые сравнения (Mann-Whitney, p < 0.005 где указано)

| Сравнение | Результат |
|-----------|-----------|
| Collie vs Labrador (show+work) | Collies выше по impulsivity, behavioural regulation, aggression threshold/novelty |
| **Working Collie vs working Labrador** | Collies выше по impulsivity, behavioural regulation, aggression threshold/novelty |
| **Show Collie vs show Labrador** | Различие **только** по aggression threshold/novelty; по impulsivity и regulation — **н.з.** |
| Work vs show (внутри породы) | Work lines выше по **responsiveness** (обе породы) |
| Neutered vs intact (males) | Кастрированные самцы выше по impulsivity, regulation, aggression threshold; **ниже** responsiveness |
| Females vs males | Females чуть выше aggression threshold/novelty (малый effect size) |

### Effect sizes

- Статистическая значимость при **малых** partial η² (< 0.06) — типично для больших n; биологическая значимость осторожна.
- **Внутрипородная** вариация больше межпородных средних различий → breed alone — слабый предиктор impulsivity.

### Выводы авторов

- **Линия (work/show) важнее «породы в среднем»** для impulsivity-профиля.
- Show breeding с фокусом на экстерьер «схлопывает» поведенческие различия между породами.
- Стереотипизация пород для законодательства и matching — **неадекватна**; нужен индивидуальный профиль.

### Ограничность DIAS для Barko

- DIAS ≠ C-BARQ; нет прямого item overlap с C-BARQ(S).
- Owner-reported; причина кастрации не контролировалась (confound).

### Релевантность для Barko

- Аргument против **breed-only** matching в K3/K5; если использовать породу — нужна **линия/назначение** (working/pet/show) или поведенческий профиль.
- Impulsivity / arousal — см. пересечение с C-BARQ(S) excitability; потенциальный external validation construct, не готовый feature без harmonization.
